## 2. Detailed findings

### #0 Stale offers served — confirmed intentional
Live answers still show ancient expiries ("Valid until 2015-12-23", "2019-06-03", "2014-07-18"; history lines ~84, 205). No expiry filter exists by design (documented fallback). **Flag for product decision**, not a code bug.

### #1 Relevance guardrail — fixed
`_context_is_relevant` (rag_engine.py:2280) + hard thresholds (`MIN_RELEVANCE_SCORE=0.35`, `STRICT=0.45`, `RELEVANCE_CHECK_SCORE=0.55`, config.py). Judging fails **open** on judge error (returns True — never silently blocks), which is the right polarity. The new `agent/` layer adds an even stricter evidence gate (see §4).

### #2 Price filters — fixed, doubly
Threaded end-to-end in the faceted path (price-threshold captured at 2021-2026, applied ~3211). Agent layer re-derives bounds deterministically (`_price_of`, `_matches_price_span`, `_concrete_span` in `agent/tools/catalog_tools.py`) and refuses superseded bounds. Bonus: grounding drops unconfirmed "under 100" components rather than fabricating them.

### #3 Silent drops — fixed
Server raises `HTTPException(500)` (app.py:528), SSE path emits error events; widget shows `CHAT_API_ERROR[lang]` with a retry affordance (index.html:1136-1147). No invisible Ollama queueing under the generation semaphore (503 + Retry-After).

### #4 Leaked template text — source fixed, one residual hole
The exact string survives only in the old export (5 hits: lines 205, 389, 439, 1102, 1378). Current code: `_llm_offer_intro` is a tiny call (num_predict=80, temperature=0.3) with a card-marker defensive regex + `_strip_scaffolding_leaks` (rag_engine.py:147-170, also CJK strip). **Residual:** no literal-phrase regex blocks "sure! here is a friendly introduction" before the intro reaches the wire. Cheap defensive addition recommended (M).

### #5 KB/FAQ contradictions — backend consistent, frontend contradicts
- Backend data audit (all greps): `data/faqs.json` refund FAQ is fully Waffarha-specific (wallet/card refunds, no cash withdrawal, 5% refund fee, 24h wallet / 15-business-day cards / 5-7-day e-wallets / 2-30-day prepaid, cashback valid 30 days for purchases only). `data/faqs_purchasing_status.json` clean (Paid/In Process/Used/Canceled/Refund = coupon statuses). No generic shipping/tracking/14-day/bank-withdrawal terms in `faqs_payment_methods.json`/`faqs_privacy.json`.
- **Frontend still ships the old generic e-commerce KB:** `MOCK_KB` in static/index.html:545-556+ answers "Where's my order?" with "the merchant ships your item / 3-7 business days", cashback "Withdraw it to your bank account", 14-day returns, cash-on-delivery — all false for the coupon model. Used by `seedChats()` (index.html:684-700) and `findAnswer()` (704-713). `data/faqs.json`/`rag_engine.py` fix is invisible to the demo path. **This is the single most user-visible remaining instance of bug #5.**

### #6 `sources` payload — partial
At rag_engine.py:4002, `sources` = `self._last_retrieved`, which is set to:
- 3063 faceted-superlative → ALL candidate `entries` (only `entries[0]` is rendered → over-inclusion);
- 3413 faceted-normal → `shown_entries` (correct);
- 3819 main hybrid path → the full retrieved pool **before** LLM filtering (docs the model may not have cited).

app.py slices to 3 (non-stream `raw_sources[:3]` at 553-558, stream `_last_retrieved[:3]` at 668-673) and remembers `raw_sources[:3]` (app.py:544). So cited != reported in the two main paths. Fix: set `_last_retrieved = shown/cited docs` at each answer build site (M).

### #7 Invented intent / blaming user — no new repro this session
Greps for "understand|تقصد|تبحث عن" surfaced only the #4 leak lines; no fresh evidence beyond SS-worthy examples. The old export predates the rewrite. **Recommend: add the ex-π repro prompts to eval and re-run before claiming fixed.** (L)

### #8 English error strings in Arabic sessions — improved
`FALLBACK_MESSAGE` (rag_engine.py:61-64) and `PERSONAL_ERROR`/`CATALOG_ERROR` (used at 3671/3686) all route through `detect_lang`. Still worth a live bilingual smoke test.

### #9 Greeting language — backend fixed, frontend partial
Backend now short-circuits `_looks_like_greeting` with `_GREETING_REPLY[lang]` keyed by reply detection (history line 72 shows "هاي" → Arabic "أهلاً بيك!" — works). Frontend: `let lang = "en"` hardcoded (index.html:680), `seedChats()` writes `STRINGS.en.greeting` + forces `findAnswer(..., "en")` for all seeds (684-700), and `setLang()` (1384-1406) **never persists** — reload resets any choice. No `localStorage`/`navigator.language` read. Fix: initialize from localStorage + emit `lang` with requests + localize seeds (M).

### #10/#11 Corruption + fake-util/gibberish — addressed
Control/bidi cleanup + CJK strip at rag_engine.py:3999 and 159-170; arabizi normalization in `agent/` facade + grounding. `_looks_like_gibberish` + `_safety_gate` (engine.py:842-855: farewell/greeting/gibberish/injection short-circuits, `_INJECTION_REPLY` etc. at 1051-1077). Guarded by FAIL-CLOSED budget caps ($MAX_AGENT_LLM_CALLS=3`, `MAX_AGENT_TOOL_CALLS=3`, config.py:331-332).

## 4. Concurrent agentic-RAG rewrite — evaluation

Verdict: **well-engineered; addresses the right systemic risks; does not touch the frontend and leaves #6's semantics in the legacy path.**

**Design (verified in source, `agent/engine.py` docstring 1-28):** 8-step bounded loop — safety gate → exactly ONE planner call → deterministic reference pass → validate → execute tools with provenance/budget → evidence gate → non-LLM relaxation (max ONE replan) → deterministic rendering. Explicit "NO freeform LLM answer": **all prices/dates/discounts come from tool-returned docs, not generation** — structurally kills #1/#2-families on the agent path.

**Per-module:**
- `agent/grounding.py` — deterministic entity grounding cross-checked against `FacetedCatalog` resolvers; drops unconfirmed entities ("unconfirmed entity dropped: <value>" trace); Arabic-digit normalization via `numbers_in_text`. Good.
- `agent/state.py` — clean AgentState/TraceStep with explicit trace kinds + confidence levels; actions distinguish CLARIFICATION from RESPOND_NONE — supports #7 reasoning traces.
- `agent/eval_metrics.py` — `classify_unnecessary_step` (redundant_refetch / unused_result / unnecessary / empty_result) gives the budget/step metrics the legacy path never had.
- `agent/tools/catalog_tools.py` — structured-first search via `FacetedCatalog` with hybrid semantic fallback; price bounds derived (`_price_of`/`_matches_price_span`/`_concrete_span`); no SQL/filesystem/arbitrary HTTP. Good surface.
- `agent/tools/cascade_tools.py` — lazy `_r()` avoids the ~47s rag_engine import at module scope; personal scope gated by `PERSONAL_QUERIES_ENABLED`; safe-failure + provenance-tagged results.
- `agent/engine.py` — `_safety_gate` at 842-855 (short-circuits for closing/greeting/gibberish/injection), bounded by config caps; reply constants localized at 1051-1077.

**Flags / discrepancies to hand the owning agent:**
1. **Doc drift:** `docs/PHASE0_ASSESSMENT.md` states `PERSONAL_QUERIES_ENABLED` defaults true; config.py:419 now false. Also 9142-doc/47s-load numbers predate the mpnet+faiss rebuild (refresh_log 2026-09-14). Update the assessment.
2. **Frontend not in scope:** MOCK_KB contradiction (#5), `let lang="en"` + non-persisting `setLang` (#9), localizing `seedChats()` — all still live. The rewrite makes this worse-looking because backend + seed demo now disagree in opposite directions.
3. **`<gen>` affordance / model drift:** AGENT_MODEL defaults to OLLAMA_MODEL (`qwen2.5:3b`); PHASE0 flags config-vs-env naming drift — still unresolved.
4. **No repro tests** for the three worst history entries ("offer koshary" irrelevant-hit, "عروض تحت 100 جنيه" price filter, "what model are you?" deflection). The suite covers gates/budgets (test_agent_engine.py), cross-ref breadth + injection + budget metrics (test_stage4_coverage.py), but the actual regression cases from the export are missing.
5. `agent/` is 100% untracked — nothing survives without an explicit commit.

**Weakest remaining failure family overall:** the legacy RAG path still runs by default for streamed chat; the agent is a parallel pipeline. Until routing picks agent-over-RAG, legacy-path issues (#4 literal leak, #6 sources semantics, score-inflation accounting) stay live.
